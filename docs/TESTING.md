## Не проверено

* С подключённым осциллографом (определение съёмного диска, отключение во время работы).
* На «чистой» Windows 10/11 — только на машине разработки с урезанным PATH.
* Прошивки, в которых формат BIN другой: такие файлы будут отклонены по полю длины.
* Распознавание надписей с символами, которых нет в 9 образцах (см. FORMAT.md).
